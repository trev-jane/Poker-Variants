# Poker-Variants
Contains rules for some of my poker variants:

Rules for "Chauss" are included in pdf and txt formats. Chauss is a wagering-based card game that stretches the genre to its limits without losing coherence and strategy. It incorporates mechanics from poker, gin rummy, Magic: the Gathering (board wipes), and others.

There is a simple program to determine four-card and six-card hand rankings (as opposed to the standard five-card poker hands). Four-card poker does not have a full house. Six-card poker has three additional hands:
  *Fuller House : Four-of-a-Kind + Pair
  *Double Set   : Two Three-of-a-Kinds
  *Three Pair   : Three Pairs
